
# Iris Flower Classification Using Machine Learning

## Project Overview
This project implements supervised machine learning algorithms to classify Iris flowers into three species: Setosa, Versicolor, and Virginica.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Machine Learning Algorithms
1. Logistic Regression
2. Decision Tree Classifier

## Project Workflow
1. Dataset loading
2. Exploratory Data Analysis
3. Data preprocessing
4. Feature scaling using StandardScaler
5. Train-test splitting (80:20)
6. Model training and prediction
7. Performance evaluation
8. Confusion matrix visualization
9. Decision boundary visualization

## Results

| Algorithm | Accuracy |
|---|---:|
| Logistic Regression | 93.33% |
| Decision Tree | 93.33% |

## Conclusion
Both machine learning algorithms achieved 93.33% accuracy on the test dataset. The project demonstrates how supervised learning algorithms can classify Iris flower species using their measured features.

## How to Run
1. Download or clone this repository.
2. Open the Jupyter Notebook.
3. Install the required libraries.
4. Run all notebook cells.
