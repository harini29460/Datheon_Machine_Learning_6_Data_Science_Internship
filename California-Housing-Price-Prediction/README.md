# California Housing Price Prediction

## 📌 Project Overview
This project uses Machine Learning Regression algorithms to predict median house values based on the California Housing dataset.

## 🎯 Project Objective
To develop and compare different regression models and identify their performance using evaluation metrics.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## 📊 Algorithms Used
1. Ordinary Least Squares (OLS) Regression
2. Ridge Regression (L2)
3. Lasso Regression (L1)

## ⚙️ Data Preprocessing
- Missing value imputation
- Correlation analysis
- Feature engineering
- Interaction feature creation
- One-Hot Encoding
- Feature standardization
- Multicollinearity analysis

## 📈 Model Evaluation
- Root Mean Squared Error (RMSE)
- Mean Absolute Error (MAE)
- R² Score

## 📉 Visualizations
- Correlation Heatmap
- Actual vs Predicted Plot
- Residual Distribution Plot

## 📂 Dataset
California Housing Dataset:
[Download Dataset](https://raw.githubusercontent.com/ageron/handson-ml2/master/datasets/housing/housing.csv)

## ▶️ How to Run the Project

1. Download the `California_Housing_Regression.ipynb` notebook.
2. Open [Google Colab](https://colab.research.google.com/).
3. Click File → Upload notebook.
4. Select the downloaded `.ipynb` file.
5. Run the code cells one by one.

## 📝 Conclusion
This project compares OLS, Ridge and Lasso Regression models for California house value prediction using different evaluation metrics and visualizations.
